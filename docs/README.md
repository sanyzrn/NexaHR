## اگر یک فایل می‌خوانید

[`open-findings.md`](open-findings.md) — **کارهای بازِ سامانه.** آنچه از دو
بازبینیِ ده‌نقشی مانده: ۴ موردِ متوسط و ۱۰ موردِ کم، هرکدام با چند خط توضیح.

موردِ محاسبه است.
